# 🎓 Student Attendance Management System

A simple, user-friendly web-based application designed to manage student records and track daily attendance efficiently. Built using **HTML, CSS, and JavaScript**, this project provides an easy way to organize students, manage classes, record attendance, and export attendance reports.

## 🚀 Features

- **Dashboard:** View attendance statistics and student information.
- **Student Management:** Add, edit, delete, and manage student records.
- **Attendance Tracking:** Mark students as Present or Absent.
- **Class Management:** Organize Theory and Lab classes.
- **Group Management:** Manage student groups from A1 to H2.
- **Date-wise Attendance:** Record attendance for different dates.
- **Search Students:** Quickly find students using the search feature.
- **Attendance History:** View previously saved attendance records.
- **Excel Export:** Export attendance reports in CSV format, compatible with Microsoft Excel.
- **TXT Export:** Download attendance reports as text files.
- **Local Storage:** Save student and attendance data in the browser.

## 💻 Installation & Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/injamul2005/Student-Attendance-Management-System.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Start managing student records and attendance.

**No additional software or installation is required.**

## 📖 How to Use

1. Open the application in your browser.
2. Add student information through the Student Management section.
3. Select the class type (Theory or Lab).
4. Select the appropriate section and group.
5. Choose the attendance date.
6. Mark students as Present or Absent.
7. Save the attendance records.
8. Export attendance reports in CSV or TXT format whenever needed.

## 💾 Data Storage

This application uses the browser's **Local Storage** to save student information and attendance records.

**Note:** Data is stored locally in the browser. Clearing browser data or using a different browser/device may affect access to saved records. Export important attendance reports regularly.
